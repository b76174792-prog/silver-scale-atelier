银鳞书庭 · 用户须知

银鳞书庭是独立维护的非官方主题管理器，为官方 Windows 宿主提供可关闭的界面主题和角色显示。请使用自己的官方账号；本软件不提供账号、模型服务或官方订阅。

运行与权限
安装包自带所需 Node 运行时，正常使用不需要源码目录、开发工具或系统预装 Node。启用主题会启动专用的官方宿主实例，并通过仅限本机的诊断连接加载主题。仅在宿主身份、活动页面及结构能够确认时启用；无法确认时会停止并显示原因。请勿将本机诊断连接开放到网络。
主题校验器需要 Microsoft Visual C++ v14 x64 运行库。缺少时，安装向导经你确认后从 Microsoft 下载锁定并校验 SHA-256 的官方安装程序，打开其完整安装界面；系统可能要求管理员确认。请完成该官方安装后再继续。拒绝、下载失败或需重启时，银鳞书庭不会继续安装或中止既有主题管理器；不会强制重启，也不会卸载共享运行库。已有可用运行库时无需为此联网。无法联网时可从 Microsoft 官方页面安装后重试：https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist 。该运行库由 Microsoft 单独提供，不适用本项目的代码许可。
关闭主题会移除主题和角色并恢复原生外观，保留一个最小控制入口；停止或退出管理器会清理自身挂载与连接。专用官方窗口继续运行时，其本机诊断端口仍存在，正常退出该窗口后关闭。官方宿主的登录与数据由官方应用管理，不要复制他人的登录资料。卸载时可保留设置或移入可恢复备份；备份仍占磁盘空间，独立 ClientProfile 始终保留。
